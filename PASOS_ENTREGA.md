# Pasos finales de entrega

## GitHub

1. Crea un repositorio público llamado \`mobile-secure-demo\`.
2. Antes del primer commit, crea tu \`secrets.properties\` local si deseas probar el proyecto.
3. Ejecuta:
   \`\`\`bash
   git status
   git check-ignore -v secrets.properties
   \`\`\`
4. Confirma que \`secrets.properties\` NO aparezca como archivo a subir.
5. Sube el contenido de este proyecto.
6. Copia el enlace público del repositorio.

## Medium

1. Abre Medium y crea una nueva historia.
2. Copia el contenido de \`MEDIUM_ARTICLE.md\`.
3. Sustituye la línea del repositorio por tu URL pública de GitHub.
4. Revisa que los bloques de código estén en formato de código.
5. Publica el artículo.
6. Copia el enlace público de Medium y entrégalo.
